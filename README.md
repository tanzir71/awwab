# Awwab

Awwab is an offline-first companion for returning to prayer and relearning Quranic Arabic. The landing page is the first milestone.

Run `npm ci` and `npm run dev`, then open the `/awwab/` path shown by Vite. The production build is available in `dist` after `npm run build`.

The [product specification](docs/SPEC.md) includes the Figma file and release criteria.
